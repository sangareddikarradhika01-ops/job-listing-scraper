# Python Job Listing Web Scraper

## About the Project

This is a Python web scraping project that extracts job listings from the Fake Python Jobs website.

The scraper collects job titles, company names, locations, descriptions, and application links.

The extracted information is saved in a CSV file.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV

## Features

- Extracts multiple job listings.
- Collects company and location information.
- Extracts job descriptions.
- Collects application links.
- Exports the data into a CSV file.

## Installation

1. Clone the repository.
2. Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## How to Run

Execute the following command:

```bash
python scraper.py
```

The extracted information will be saved in `jobs.csv`.
